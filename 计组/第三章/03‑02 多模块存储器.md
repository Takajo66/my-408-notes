# 03‑02 多模块存储器
## 1. 核心概念
多模块存储器将主存划分为多个独立存储体，依靠多体并行访问，**提升主存整体吞吐率**。分为**连续编址（高位交叉编址）**、**交叉编址（低位交叉编址）**。

### 1.1 连续编址（高位交叉编址）
> 主存地址：**高位 = 体号；低位 = 体内地址**
同一个存储体内地址连续；一个存储体存满之后，才使用下一个存储体。
普通CPU顺序访问连续内存，无法实现并行；只有DMA同时读写多个存储体时，性能才可以提升。

### 1.2 交叉编址（低位交叉编址）
> 主存地址：**高位 = 体内地址；低位 = 体号**
连续物理地址分散分布到不同存储体。以4体举例：地址0在M0，1在M1，2在M2，3在M3，4回到M0。
存在两种工作模式：轮流启动、同时启动。

#### ① 轮流启动（流水线模式，408高频）
适用条件：**单个存储模块存储字长 = 总线数据线宽度**
$m$ 为存储体数量，$T$ 为单个存储体存储周期。
流水线稳定之后，**每隔 $T/m$ 可以读出一个数据**。
> 重要前提：每一个存储体仍然需要完整走完自己的存储周期 $T$；只是各个存储体启动访问的时间互相错开。

#### ② 同时启动（并行读出模式）
适用条件：所有模块并行输出的总位数 = 总线数据线宽度。
同一时刻同时启动全部存储体，等待完整存储周期 $T$，一次性读出多个字；没有流水线重叠效果。

> 参数说明
- $m$：存储体数量
- $T$：单个存储体的存储周期
- $r$：总线传输周期，完成一次数据传输的总耗时。
  - 轮流启动流水线稳定后：$r = \dfrac{T}{m}$
  - 同时启动：$r = T$

## 2. 原理与推导
### 2.1 连续编址地址拆分示例
4个体，地址高2位代表体号，低8位代表体内地址。
M0：0~255；M1：256~511；M2：512~767；M3：768~1023。
顺序访问连续地址全部落在同一个存储体内，无法并行加速。

### 2.2 低位交叉编址地址拆分示例
4个体，地址高8位是体内地址，低2位是体号。
地址序列：0(M0),1(M1),2(M2),3(M3),4(M0),5(M1)……
连续地址落在不同存储体，才可以发挥流水线轮流启动的加速效果。

### 2.3 轮流启动时间计算公式（解题直接套用）
$m$个体低位交叉流水线，读取连续 $N$ 个字总耗时：
$$ T_{\text{总}}= T + (N-1)\cdot \frac{T}{m} $$
> 原理说明：第一个存储体需要完整存储周期 $T$；之后每间隔 $T/m$ 完成下一个体的数据读出。

> 限制条件：只有访问**连续主存块**，低位交叉流水线才可以发挥加速效果；随机离散地址访问没有性能提升。

## 3. 典型题型
1. 区分高位交叉（连续编址）、低位交叉（交叉编址），识别地址哪一部分是体号。
2. $m$体低位交叉轮流启动，计算读取连续N个字总时间。
3. 区分轮流启动、同时启动，判断总线传输周期 $r$。
4. 判断：连续编址对CPU顺序访问能否提高吞吐率。

## 4. 易错点
❌误区1：低位交叉会缩短单个存储体自身存储周期T。
✅纠正：每个存储体存储周期T保持不变；依靠错开启动时间实现流水线重叠。

❌误区2：低位交叉一定可以提速。
✅纠正：仅访问**连续地址序列**流水线生效；随机离散地址没有加速。

❌误区3：轮流启动模式下，模块经过 $T/m$ 就完成本次读写。
✅纠正：存储体必须经过完整 $T$ 才完成一次读写；$T/m$ 只是两次启动之间的时间间隔。

❌误区4：混淆高低位交叉体号位置。
✅纠正：高位交叉（连续编址）：**高位是体号**；低位交叉（交叉编址）：**低位是体号**。
