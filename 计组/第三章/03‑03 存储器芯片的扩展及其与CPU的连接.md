# 03‑03 存储器芯片的扩展及其与CPU的连接
## 1. 核心概念
### 1.1 基础定义
存储芯片规格统一格式：$\boldsymbol{\text{单元数} \times \text{单元位数}}$。
- 单元数：决定地址线数量，满足 $2^{\text{地址线根数}} = \text{单元数}$；这部分地址称为**片内地址**。
- 单元位数：决定数据线根数，对应存储字长。

扩展目的：单片芯片容量不足，通过组合多片芯片，构建满足总容量、总位宽的主存，再对接CPU的MAR（地址）、MDR（数据）与控制总线。

### 1.2 三种扩展方式
1. **位扩展（扩充字长）**
    条件：芯片单元数量足够，仅数据线位宽不足。
    特点：单元总数不变，只增加存储字长；同一组内所有芯片必须同时被选中。
    ![[Pasted image 20261018155346.png]]![[Pasted image 20261018155108.png]]

2. **字扩展（扩充存储单元数量）**
    条件：芯片位宽足够，仅存储单元总数不足。
    特点：字长不变，扩大总存储容量；不同芯片占用不同地址区间，同一时刻只选中目标芯片组。
    ![[Pasted image 20261018155414.png]]
![[Pasted image 20261018155311.png]]

3. **字位同时扩展**
    条件：单元数量、位宽均不满足要求。
    解题推荐顺序：**先做位扩展组成芯片组，再对芯片组做字扩展**；硬件层面两种顺序均可，但考题统一采用先位后字的流程。

### 1.3 三类总线连接规则
1. **地址总线**
    低位地址 = 片内地址，直接接入芯片地址引脚；
    剩余高位地址送入地址译码器，生成各个芯片/芯片组的片选信号$\overline{CS}$。

2. **数据总线**
    位扩展：各组芯片数据线分别接到数据总线不同位；
    字扩展：所有芯片数据线并联到同一组数据总线；依靠片选保证同一时刻只有一路输出。

3. **控制总线**
    - $\overline{CS}$（片选）：决定芯片是否被选中参与本次访问；只有片选有效，芯片才进入工作状态。
    - $\overline{WE}$（写允许，低电平有效）：控制写入操作；
    - $\overline{OE}$（输出允许，低电平有效）：控制读出操作；
    所有同组芯片的读写控制线并联。

### 1.4 地址划分核心原则
- 片内地址：由单片芯片的单元个数决定，只用来选择芯片内部存储单元。
- 片选地址：地址高位，用来区分不同芯片/芯片组，用于译码产生片选。
> 区分两个地址位数：
> 1）片内地址位数：由单片芯片容量决定；
> 2）整个主存地址位数：由主存总容量决定；二者不可混淆。

## 2. 原理与推导
### 2.1 总芯片数量计算公式
$$ N_{\text{总}} = \frac{D_{\text{目标}} W_{\text{目标}}}{D_{\text{单片}} W_{\text{单片}}} $$
其中：
- $D$：存储单元数（字数）；
- $W$：每个存储单元的位数；
- 字扩展倍数：$\displaystyle \frac{D_{\text{目标}}}{D_{\text{单片}}}$；
- 位扩展倍数：$\displaystyle \frac{W_{\text{目标}}}{W_{\text{单片}}}$。

当目标规格能够由整片芯片直接组成时：
$$ N_{\text{总}} = \frac{D_{\text{目标}}}{D_{\text{单片}}} \times \frac{W_{\text{目标}}}{W_{\text{单片}}} $$

### 2.2 位扩展计算与接线示例
题目：用 $8K\times4bit$ 芯片构成 $8K\times8bit$ 存储器
1. 位倍数：$8/4=2$片；字倍数=1，不需要字扩展。
2. 接线：2片地址线、$\overline{CS}$、$\overline{WE}$、$\overline{OE}$全部并联；一片接低4位数据线，另一片接高4位数据线。

### 2.3 字扩展计算与接线示例
题目：用 $8K\times8bit$ 芯片构成 $32K\times8bit$ 存储器
1. 字倍数：$32K/8K=4$片；位倍数=1，不需要位扩展。
2. 地址拆分：$8K=2^{13}$，低13位为片内地址；剩余高位送入2‑4译码器，输出4路分别作为4片芯片的$\overline{CS}$。
3. 接线：所有芯片数据线并联；地址、读写控制线并联；仅片选相互独立。

### 2.4 字位同时扩展解题步骤（固定流程）
1. 先算位扩展倍数，算出每组需要几片芯片，组成满足目标位宽的芯片组；
2. 再算字扩展倍数，算出一共需要多少组芯片；
3. 总片数 = 每组片数 × 组数；
4. 拆分地址：低位为片内地址，剩余高位译码产生各组片选。

示例：$2K\times4bit$ 芯片扩展为 $8K\times8bit$
1. 位扩展：$8/4=2$片为一组，得到 $2K\times8bit$；
2. 字扩展：$8K/2K=4$组；
3. 总片数：$2\times4=8$片；
4. 片内地址：$2K=2^{11}$，低11位接芯片；高位译码产生4组片选。

### 2.5 ROM+RAM混合扩展（系统主存常考）
1. 地址分段：系统引导区用ROM，用户数据区用RAM；
2. 分别对ROM区域、RAM区域做字/位扩展；
3. 地址高位译码，分别产生ROM片选、RAM片选，保证两个区域地址不重叠。

## 3. 典型题型
1. 给定芯片规格与目标主存容量，计算总芯片数量。
2. 判断扩展类型：位扩展、字扩展、字位同时扩展。
3. 地址拆分：区分片内地址与片选地址，确定译码器输入；区分片内地址位数与主存总地址位数。
4. 给出物理地址，判断该地址选中哪一片芯片/芯片组。
5. ROM与RAM混合搭建主存，划分地址区间、设计片选逻辑。
6. 线选法与译码片选法的区别与地址范围计算。

## 4. 易错点
❌误区1：位扩展的多片芯片使用独立片选信号。
✅纠正：位扩展属于同一组，必须共用同一个$\overline{CS}$，保证多片同时被选中。

❌误区2：字扩展时，不同芯片数据线分开，不并联到总线。
✅纠正：字扩展所有芯片数据线并联；依靠片选信号互斥，保证同一时刻只有一片驱动总线，避免总线冲突。

❌误区3：把地址高位直接接到芯片地址引脚。
✅纠正：**低位是片内地址送入芯片；高位用来译码生成片选**，不能颠倒。

❌误区4：强制规定字位扩展硬件必须先位后字。
✅纠正：硬件上两种顺序都可以实现；**仅做题时推荐先位扩展拼成芯片组，再做字扩展**，简化地址划分。

❌误区5：片选$\overline{CS}$可以控制读写动作。
✅纠正：$\overline{CS}$只决定芯片是否被选中参与访问；真正控制读/写的是$\overline{WE}$与$\overline{OE}$读写信号线。

❌误区6：混淆片内地址位数与主存总地址位数。
✅纠正：片内地址由单片容量决定；总地址位数由整个主存总容量决定，二者不能等同。

## 5. 知识关联
### 前置知识
- [[03‑01 存储器概述]]：MAR、MDR、存储字长、地址线与数据线的基础概念；没有MAR/MDR，无法完成地址与数据总线的连接。
- [[03‑01 存储器概述#SRAM与DRAM]]：扩展所用的存储芯片分为SRAM、DRAM、ROM；$\overline{WE}$、$\overline{OE}$为SRAM典型控制信号，ROM只有读出控制，无写信号。

### 同级概念（易混淆对比）
- [[03‑02 多模块存储器]]：多模块低位交叉是存储体级别的并行结构；存储器芯片字扩展是芯片级的容量扩充；二者都依靠高位地址划分存储单元，但层级不同。

### 操作与原理
- [[03‑03 存储器芯片的扩展及其与CPU的连接#地址划分核心原则]]：所有片选译码逻辑，都建立在“片内地址+片选地址”的地址拆分规则之上；地址拆分错误，片选逻辑必然出错。

### 题型关联
- [[03‑02 多模块存储器]]：大题常联合考查：先用芯片扩展搭建主存，再设计低位交叉多体结构，提升主存吞吐率；解题顺序：先完成芯片扩展→划分地址→再设计多模块体号。

### 后续知识
- [[03‑04 Cache]]：Cache由SRAM芯片搭建，同样需要使用位扩展、字扩展完成芯片组合；本章扩展技术是Cache硬件设计的基础。

答案：B；位扩展多片必须同时选中，共用一路片选。

<details>

4.【计算】用 $1K \times 4bit$ 芯片构成 $4K \times 8bit$ 主存，求总片数与片内地址位数。
