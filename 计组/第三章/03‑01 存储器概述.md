# 03‑01 存储器概述
## 1. 核心概念
存储器功能：存放程序与数据。
存储器体系分层：寄存器 → Cache → 主存 → 辅存 → 海量后备存储器。
> 分层变化规律：离CPU越近，**速度越快、容量越小、位成本越高**；数据仅在**相邻两层**之间传输，传输单位为定长块。

### 1.1 存储器四种分类维度
#### ①按存取方式分类
1. **随机存取**：按**地址**访问，任意单元访问时间相等。例：RAM、ROM。
2. **顺序存取**：按物理顺序读写，访问时间和数据存放位置强相关。例：磁带。
3. **直接存取**：先定位到存储区域，区域内部顺序读写。例：磁盘。
4. **相联存取（相联存储器）**：按**内容/关键字**检索，不使用地址。例：TLB快表。

#### ②按信息可改写性分类
- RAM（随机读写存储器）：可读可写。
- ROM（只读存储器）：正常工作模式只读；部分型号可在特殊条件擦写。

#### ③按断电信息是否保存（易失/非易失）
- **易失性**：断电数据丢失。SRAM、DRAM、Cache。
- **非易失性**：断电数据保留。MROM、PROM、EPROM、EEPROM、Flash、磁盘、光盘。

#### ④按在计算机系统中的功能分类
1. 寄存器：CPU内部，速度最快，容量极小。
2. Cache高速缓存：CPU与主存之间，SRAM实现。
3. 主存储器（主存）：RAM+ROM，运行程序，DRAM为主。
4. 辅助存储器（辅存）：磁盘，长期保存程序数据。
5. 海量后备存储器：磁带库、光盘库，归档备份。

### 1.2 RAM分类（SRAM / DRAM，**是否刷新为核心考点**）
#### SRAM 静态随机存储器
- 存储介质：**触发器**存储0、1。
- ✅**不需要刷新**；读操作不会破坏存储内容，读后不需要再生。
- 特点：速度快；集成度低；功耗大。
- 应用：Cache。

#### DRAM 动态随机存储器
- 存储介质：**电容存储电荷**；电容漏电，电荷随时间流失。
- ✅**必须定期刷新维持数据**。
- 特点：集成度高；功耗低；速度低于SRAM。
- 应用：计算机**主存**。
- **地址复用技术**：行地址、列地址分时复用同一组地址线，减少芯片引脚。
  控制信号：$\overline{RAS}$行地址选通、$\overline{CAS}$列地址选通、$\overline{WE}$读写、$\overline{OE}$输出使能。
> DRAM刷新：**按行刷新**，一次刷新一整行全部单元。普通读操作仅仅刷新被选中的那一行，其余行依靠内部刷新计数器自动刷新。

##### DRAM三种刷新方式
1. **集中刷新**
在规定刷新周期内，前一段时间正常读写；末尾集中完成全部行的刷新。
- 优点：读写期间无刷新干扰；
- 缺点：存在一段完全不能访问存储器的**死区**。

2. **分散刷新**
把每一个存储周期拆分为「读写时间 + 刷新时间」。
- 优点：无死区；
- 缺点：存储周期翻倍，整机存取速度下降。

3. **异步刷新【考研最高频】**
把总刷新时间均匀分摊分配给每一行，各行分散刷新。
- 优点：死区极短几乎可忽略；兼顾速度，综合性能最优。

### 1.3 ROM系列完整对比
|类型|写入时机|擦除方式|特点|
|---|---|---|---|
|MROM掩模ROM|工厂制造固化|不可擦除|出厂内容固定|
|PROM一次可编程ROM|用户一次性烧录|不可擦除|只能写一次|
|EPROM|紫外线擦除|整块全部擦除|不能按字节擦写|
|EEPROM（E²PROM）|电擦写|按字节擦除|可单字节改写|
|Flash闪存|电擦写|**按块擦除**|SSD介质；ROM类、非易失|

> 重要提醒：Flash属于ROM大类，不是RAM！断电数据保留。

### 1.4 CPU与主存接口寄存器 MAR、MDR
- **MAR（存储器地址寄存器）**：存放主存访问地址；$\text{MAR位数} = \text{地址线根数}$，决定寻址空间。
- **MDR（存储器数据寄存器）**：存放主存读写的数据；$\text{MDR位数}=\text{数据线宽度}$。

> 三组容易混淆概念
1. **按字节编址**：1存储单元 = 1字节 = $8\,\text{bit}$；一个地址对应8bit。
2. **机器字长**：CPU一次整数运算处理二进制位数，等价于数据线宽度。
3. **存储字长**：一个存储单元存放二进制位数；按字节编址下存储字长固定8bit。

### 1.5 存储周期、存取时间
- **存取时间**：从启动读/写，到操作完成的时间。
- **存储周期**：连续两次访问存储器的最小时间间隔。包含存取时间 + 器件稳定恢复时间。
> $$\boldsymbol{存储周期 > 存取时间}$$
> 必须等待完整存储周期结束，才能发起下一次访问。

## 2. 原理与推导
### 2.1 主存读操作完整流程
1. CPU将待访问地址送入MAR；
2. 地址经地址线送入主存内部地址寄存器；
3. 地址译码器译码选中对应存储单元，CPU发出读控制信号；
4. 存储单元数据输出到数据线上；
5. 数据送入MDR，读操作结束。

### 2.2 主存写操作完整流程
1. 访问地址送入MAR，待写入数据送入MDR；
2. 地址送入主存，译码选中目标存储单元，CPU发出写控制信号；
3. MDR内的数据通过数据线写入选中存储单元。

> 补充：64位机器按字节编址，数据线64bit，一次吞吐64bit；但**每个地址仅对应8bit**，读写一个机器字需要多次访问存储单元。

### 2.3 DRAM地址复用原理
完整地址拆分为行地址、列地址；同一组地址线先后输出两部分；$\overline{RAS}$锁存行地址，$\overline{CAS}$锁存列地址，减少芯片引脚数量。

### 2.4 DRAM刷新底层原理
电容会漏电，电荷丢失数据失效；刷新操作对行内全部单元补充电荷；读仅刷新被访问行，其余行依靠硬件计数器自动完成。

## 3. 典型题型
1. 存储器分类判断：区分4种存取方式；区分易失/非易失。
2. SRAM、DRAM对比选择题：是否刷新、存储原理、适用场景。
3. ROM各个类型特性辨析，判断Flash类别。
4. DRAM刷新计算题：计算死区时长、刷新间隔、行数。
5. MAR、MDR位数计算，求解主存寻址空间大小。
6. 区分存取时间与存储周期概念辨析。
7. 判断编址方式：按字节编址，区分机器字长、存储字长。

## 4. 易错点
❌误区1：所有RAM都需要刷新。
✅纠正：**仅DRAM需要刷新；SRAM触发器存储，不需要刷新**。

❌误区2：ROM全部不可写入。
✅纠正：EEPROM、Flash属于ROM，支持电擦写；只是正常工作模式默认只读。

❌误区3：Flash属于RAM。
✅纠正：Flash属于ROM类，**非易失，断电数据保留**。

❌误区4：存取时间等于存储周期。
✅纠正：存储周期包含稳定恢复时间，一定大于存取时间。

❌误区5：DRAM执行读操作，刷新芯片全部行。
✅纠正：读仅刷新当前被访问的一行；其余行由内部刷新计数器完成。

❌误区6：机器字长一定等于存储字长。
✅纠正：按字节编址存储字长固定8bit；机器字长等于数据线宽度，可以大于8bit。

❌误区7：相联存储器依靠地址访问。
✅纠正：相联存储器依靠内容（关键字）检索，不依靠地址。
