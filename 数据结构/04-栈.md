# 栈

## 一、栈的定义

栈是一种只能在一端进行插入和删除操作的线性表。

允许插入和删除的一端称为栈顶，另一端称为栈底。

栈遵循后进先出原则（LIFO，Last In First Out）。

例如：依次将 a、b、c 入栈，则出栈顺序为 c、b、a。

## 二、栈的基本操作

- 初始化：创建空栈。
- 入栈（Push）：将元素加入栈顶。
- 出栈（Pop）：删除并取出栈顶元素。
- 取栈顶元素：读取栈顶元素，但不删除它。
- 判空：判断栈中是否有元素。

注意：空栈不能执行有效的出栈操作；容量有限的顺序栈不能在栈满时继续入栈。

## 三、顺序栈

顺序栈使用数组存储栈中元素。

### 1. 栈顶指针

课件中的顺序栈示意图采用栈顶指针指向栈顶元素，并指出：

- top = -1 时栈空。

这意味着数组下标从 0 开始，空栈时 top 位于第一个元素之前。

注意：不同教材可能采用 top 指向栈顶元素或指向下一个空位置的约定。判断栈空、栈满以及入栈和出栈时，必须先确认题目采用哪种定义。

### 2. 入栈

在栈顶位置加入新元素，并更新栈顶指针。

若 top 指向当前栈顶元素，典型思路是先将 top 加 1，再将新元素存入对应位置。

入栈前需要检查栈是否已满。

### 3. 出栈

删除当前栈顶元素，并让栈顶指针退回到新的栈顶位置。

出栈前需要检查栈是否为空。

### 4. 取栈顶元素

读取当前栈顶元素，不改变栈的内容和栈顶位置。

## 四、共享栈

共享栈让两个栈共用同一片数组空间，通常从数组两端向中间增长。

课件给出的约定：
- 栈 S1 的栈顶指针 top1 从左向右增长。
- 栈 S2 的栈顶指针 top2 从右向左增长。
- 两栈共享空间时，top2 - top1 = 1 表示栈满。

共享栈的优点是可以更灵活地利用数组空间，减少一部分空间闲置。

## 五、链栈

链栈使用链式存储实现栈。

它通过结点指针连接元素，通常在链表的一端完成入栈和出栈。

### 链栈出栈的基本思路

1. 判断栈是否为空。
2. 保存栈顶元素。
3. 临时保存原栈顶结点，以便释放空间。
4. 修改栈顶指针，使其指向新的栈顶结点。
5. 释放原栈顶结点。

链栈不需要像固定容量的顺序栈那样预先划定全部元素空间，但仍受可用内存限制。

## 六、栈的应用

### 1. 括号匹配

括号匹配需要满足：
- 左括号和右括号类型相同。
- 括号必须按正确顺序闭合。
- 每个右括号都必须有对应的左括号。

基本思路：
1. 遇到左括号，将其压入栈。
2. 遇到右括号，检查栈顶是否为与之匹配的左括号。
3. 匹配成功则弹出栈顶。
4. 如果没有可匹配的左括号，或类型不一致，则匹配失败。
5. 扫描结束后，栈也必须为空。

为什么用栈？
因为最后遇到的、尚未匹配的左括号，必须最先与右括号匹配。

### 2. 表达式求值

表达式的三种常见形式：

- 中缀表达式：运算符位于操作数之间，例如 5 + 8。
- 后缀表达式：运算符位于操作数之后，例如 5 8 +。
- 前缀表达式：运算符位于操作数之前，例如 + 5 8。

#### 后缀表达式求值

1. 从左向右扫描表达式。
2. 遇到操作数，压入栈。
3. 遇到运算符，取出所需的操作数进行运算。
4. 将结果压回栈。
5. 扫描结束后，栈顶即为最终结果。

对于减法、除法等不满足交换律的运算，必须注意操作数顺序。

#### 中缀转后缀

1. 建立一个空运算符栈。
2. 遇到操作数，直接输出。
3. 遇到运算符，弹出栈中优先级大于或等于当前运算符的运算符并输出；遇到左括号或栈空时停止。
4. 将当前运算符入栈。
5. 遇到左括号，将其入栈。
6. 遇到右括号，依次弹出运算符并输出，直到左括号弹出。
7. 扫描结束后，输出栈中剩余运算符。

实际解题时还需结合运算符优先级、结合性和括号规则。

### 3. 数制转换

课件以十进制转换为八进制为例。

将非负整数 N 转换为 d 进制时：

1. 计算 N % d，得到当前余数。
2. 计算 N = N / d，使用整数除法。
3. 重复上述过程，直到 N 为 0。
4. 将所有余数按产生顺序的逆序排列，得到转换结果。

例：1348 转换为八进制。

1348 ÷ 8 = 168，余 4
168 ÷ 8 = 21，余 0
21 ÷ 8 = 2，余 5
2 ÷ 8 = 0，余 2

余数逆序排列，结果为 2504。

为什么需要栈？
因为余数产生的顺序与最终数位的输出顺序相反，栈的后进先出特性正好可以反转顺序。

### 4. 递归

递归执行过程中，程序需要保存尚未完成的调用状态。

这些调用状态具有后进先出的特点，因此可以使用栈来理解递归的执行过程。

## 七、卡特兰数与出栈序列

课件提出：n 个元素依次入栈，有多少种不同的出栈方式？

答案与卡特兰数有关：

C_n = 1/(n+1) × C(2n,n)

其中 C(2n,n) 表示从 2n 个元素中选取 n 个的组合数。

例如：
- n = 1：1 种。
- n = 2：2 种。
- n = 3：5 种。

该公式适用于 n 个元素按固定顺序入栈、通过栈操作产生不同出栈序列的情况。

## 八、本章易错点

1. 栈是后进先出，不是先进先出。
2. 出栈操作会删除栈顶元素；取栈顶元素不会删除。
3. 栈顶指针的定义因教材约定而异，不能死记一个通用的栈空条件。
4. 后缀表达式求值时，不能颠倒减法、除法的操作数。
5. 数制转换的余数要逆序输出。
6. 括号匹配不仅要看类型，还要看闭合顺序。
