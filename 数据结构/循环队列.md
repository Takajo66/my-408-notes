# 循环队列
## 1. 核心概念
循环队列：用一维数组模拟环形队列，解决顺序队列**假溢出**问题。
两个指针：
- `front`：队头指针
- `rear`：队尾指针

⚠️ **408存在两套指针定义，做题必须以题干描述为准，禁止死记一套**

【定义A｜教材默认】
`front` 指向队头元素；`rear` 指向队尾元素**下一个空闲位置**。牺牲1个存储位置区分队空、队满。
- 空队列：$\boldsymbol{front == rear}$
- 满队列：$\boldsymbol{(rear+1)\bmod n = front}$

【定义B｜题干自定义（2011真题模式）】
`front` 指向队头元素；`rear` **直接指向队尾元素本身**。
- 空队列约定：$\boldsymbol{front == rear}$
- 入队规则：新元素放在 $(rear+1)\bmod n$，之后将 `rear` 更新到该位置。

## 2. 原理与推导
循环队列下标移动通用公式：
$$\text{新下标} = (\text{旧下标}+1) \bmod n$$
- 入队操作：向后移动 `rear`
- 出队操作：向后移动 `front`

> 2011真题推导逻辑（定义B场景）
> 要求第一个入队元素存入 $A[0]$，即：
> $$(rear_{初始}+1)\bmod n=0$$
> 解得 $rear_{初始}=n-1$。
> 空队列条件 $front == rear$，因此 $front_{初始}=n-1$。

### 循环队列长度计算
- 定义A（标准，rear指向队尾下一位）：
$$\text{元素个数}= (rear-front+n)\bmod n$$
- 定义B（rear直接指向队尾元素）：
$$\text{元素个数}= (rear-front+1+n)\bmod n$$

区分队空队满的另外两套补充方案：
1. 增设`tag`标记：标记最近一次是入队/出队，不牺牲存储空间。
2. 增设`num`计数器：直接记录当前队列元素数目，逻辑最简单。

## 3. 典型题型
1. 给定`front/rear`自定义定义，求初始化`front`、`rear`值（2011真题）
2. 给定指针，计算循环队列内部元素个数
3. 根据不同定义，判断队列空、队列满条件
4. 入队、出队后，跟踪`front`、`rear`指针变化

## 4. 易错点
❌ 误区：背死一套`front/rear`含义，不阅读题干。
✅ 纠正：408题干可以重新定义`front`、`rear`含义，**一切以题目文字为准！**

❌ 误区：两套定义混用队列长度计算公式。
✅ 纠正：先识别题目属于定义A还是定义B，再代入对应长度公式。

❌ 误区：不理解假溢出。
✅ 纠正：普通顺序数组队列，数组前端存在空闲位置，但`rear`走到数组末尾无法入队；循环队列使用模运算解决假溢出。

❌ 混淆：循环队列（**顺序存储‑数组实现**）≠循环链表（**链式存储‑链表实现**），二者完全不同。

## 6. 自测
1.【2011真题】已知循环队列存储在一维数组$A[0\cdots n-1]$中，且队列非空时front和rear分别指向队头元素和队尾元素。若初始时队列为空，且要求第1个进入队列的元素存储在A[0]处，则初始时front和rear的值分别是（）。
A. 0, 0
B. 0, $n-1$
C. $n-1$, 0
D. $n-1$, $n-1$

<details>
<summary>点击查看答案</summary>

答案：B

推演：
题干约定：队列非空时，front指向队头元素，rear指向队尾元素。
入队规则：新元素放在$(rear_{初始}+1)\bmod n$，之后更新rear，front入队过程保持不变。
要求第1个元素存入A[0]，$(rear_{初始}+1)\bmod n = 0$，算出$rear_{初始}=n-1$。
入队完成后front必须指向A[0]，入队时front不变，所以$front_{初始}=0$。

模拟：
初始 $front=0，rear=n-1$（队空）
第一次入队，位置=$(n-1+1) \bmod n =0$，元素存入A[0]，rear更新为0。
队列非空：front=0指向队头A[0]，rear=0指向队尾A[0]，完全满足题干条件。

❌D选项错误：初始front=n‑1，入队之后front依然是n‑1，但是队头元素在A[0]，front没有指向队头，违反题干定义。
</details>
