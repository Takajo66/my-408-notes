
# 循环队列
## 1. 核心概念
循环队列：用一维数组模拟环形队列，解决顺序队列"假溢出"问题。
两个指针：
- front：队头指针
- rear：队尾指针

⚠️ 408有两套定义，**必须以题干描述为准**
1. 【定义A 教材默认】
front 指向队头元素；rear 指向队尾元素**下一个空闲位置**。牺牲1个位置区分空/满。
空队列：front == rear；
满队列：$(rear+1)\bmod n = front$。

2. 【定义B 本题（题干自定义）】
front 指向队头元素；rear 直接指向**队尾元素本身**。
空队列约定：front == rear。
入队规则：新元素放在 $(rear+1)\bmod n$，之后 rear 更新到该位置。

## 2. 原理与推导
循环队列下标移动公式：
$$\text{新下标} = (\text{旧下标}+1) \bmod n$$
- 入队：向后移动rear
- 出队：向后移动front

本题推导逻辑：
要求第一个入队元素存入A[0]，即 $(rear_{初始}+1)\bmod n=0$
解得 $rear_{初始}=n-1$
空队列条件 front == rear，所以 front初始 = n-1。

## 3. 典型题型
1. 给定front/rear定义，求初始化front、rear值（2011真题本题）
2. 循环队列求元素个数
    - 定义A(标准)：元素个数 $=(rear-front+n)\bmod n$
    - 定义B(rear指向队尾元素)：元素个数 $=(rear-front+1+n)\bmod n$
3. 判断队列空、队列满条件

## 4. 易错点
1. ❌ 误区：背死一套front/rear含义，不读题干。
✅ 纠正：**408题干可以重新定义front、rear含义，一切以题目文字为准！**
2. ❌ 混淆两种定义下，队列长度计算公式不一样。
3. ❌ 假溢出：顺序数组队列，前面有空位却不能入队，循环队列就是解决这个问题。
