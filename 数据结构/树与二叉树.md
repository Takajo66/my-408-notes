# 树与二叉树

> 关联：[[二叉树性质]] [[树与二叉树]] [[Trie字典树]]

## 一、树的基础定义与术语

### 1. 树的定义

树是 \(n(n\ge 0)\) 个结点的有限集合。

- **空树**：\(n=0\)。
- **非空树**：有且仅有一个根结点，其余结点划分为若干个互不相交的子树。
- 树是一种**一对多**的递归数据结构。

### 2. 核心术语

1. **结点**：包含数据元素及指向其子树的分支。
2. **结点的度**：结点拥有的子树个数。
3. **树的度**：树中所有结点的度的最大值。
4. **叶子结点（终端结点）**：度为 0 的结点。
5. **分支结点（非终端结点）**：度不为 0 的结点。
6. **双亲、孩子、兄弟**：结点之间的直接关系。
7. **祖先、子孙**：结点之间的间接关系。
8. **结点的层次**：根结点为第 1 层，其孩子位于第 2 层，以此类推。
9. **树的深度（高度）**：树中结点的最大层次。
10. **森林**：若干棵互不相交的树的集合。

### 3. 树的基础公式

1. 结点总数 = 所有结点的度数之和 \(+1\)。

   \[
   n=1+\sum_{i=1}^{n}d_i
   \]

2. \(m\) 叉树第 \(i\) 层最多有 \(m^{i-1}\) 个结点。

3. 高度为 \(h\) 的 \(m\) 叉树最多有：

   \[
   n_{\max}=\frac{m^h-1}{m-1}\quad(m>1)
   \]

---

## 二、二叉树

### 1. 二叉树的定义

二叉树是 \(n(n\ge 0)\) 个结点的有限集合，具有以下特点：

1. 每个结点最多有两个孩子，不存在度大于 2 的结点。
2. 每个结点的子树分为左子树和右子树，**左右次序不能颠倒**。

> 注意：二叉树不等于度为 2 的树。二叉树允许结点的度为 0、1 或 2；而度为 2 的树要求树的度恰好为 2。

### 2. 二叉树的重要性质

1. 第 \(i\) 层至多有 \(2^{i-1}\) 个结点，\(i\ge 1\)。

2. 深度为 \(k\) 的二叉树最多有：

   \[
   n_{\max}=2^k-1
   \]

3. 对任意非空二叉树：

   \[
   n_0=n_2+1
   \]

   其中：

   - \(n_0\)：度为 0 的结点数，即叶子结点数。
   - \(n_1\)：度为 1 的结点数。
   - \(n_2\)：度为 2 的结点数。

   **推导：**

   结点总数：

   \[
   n=n_0+n_1+n_2
   \]

   除根结点外，每个结点都有一条入边，因此边数为：

   \[
   e=n-1
   \]

   从结点的出度计算边数：

   \[
   e=n_1+2n_2
   \]

   联立得：

   \[
   n_0+n_1+n_2-1=n_1+2n_2
   \]

   整理得：

   \[
   \boxed{n_0=n_2+1}
   \]

### 3. 特殊二叉树

#### （1）满二叉树

深度为 \(k\) 的满二叉树，每一层的结点都达到最大数量。

- 总结点数：

  \[
  n=2^k-1
  \]

- 第 \(i\) 层结点数：

  \[
  n_i=2^{i-1}
  \]

#### （2）完全二叉树

深度为 \(k\)、结点数为 \(n\) 的二叉树，与同深度的满二叉树按层序编号时，编号为 \(1\sim n\) 的结点一一对应。

**核心性质：**

- 叶子结点只可能出现在最下两层。
- 最下层结点集中在该层最左边。
- 只有最后一层可能不满，且缺少的结点都在右侧。

**结点数与深度的关系：**

\[
\boxed{k=\lfloor\log_2 n\rfloor+1}\quad(n\ge1)
\]

**层序编号性质（从 1 开始编号）：**

对于编号为 \(i\) 的结点：

- 双亲结点：\(\lfloor i/2\rfloor\)，适用于 \(i>1\)。
- 左孩子：\(2i\)，前提是 \(2i\le n\)。
- 右孩子：\(2i+1\)，前提是 \(2i+1\le n\)。

> 易错：以上编号公式要求结点从 1 开始编号。如果数组下标从 0 开始，公式会发生变化。

### 4. 二叉树的存储结构

#### （1）顺序存储

使用数组存储二叉树结点，通常适合完全二叉树。

- 优点：访问结点方便。
- 缺点：对于斜树等形态不规则的二叉树，会浪费大量存储空间。

#### （2）二叉链表

每个结点包含数据域、左孩子指针和右孩子指针。

```c
typedef struct BiTNode {
    TElemType data;
    struct BiTNode *lchild, *rchild;
} BiTNode, *BiTree;

#### （3）三叉链表

在二叉链表的基础上增加双亲指针 `parent`，方便查找双亲结点。

### 5. 二叉树的遍历

遍历：按照某种规则访问二叉树中的每个结点，且每个结点恰好访问一次。

| 遍历方式 | 缩写 | 访问顺序 |
|---|---|---|
| 先序遍历 | NLR | 根 → 左子树 → 右子树 |
| 中序遍历 | LNR | 左子树 → 根 → 右子树 |
| 后序遍历 | LRN | 左子树 → 右子树 → 根 |
| 层次遍历 | — | 从上到下、同层从左到右（借助队列） |

#### （1）先序遍历

```c
void PreOrder(BiTree T) {
    if (T) {
        visit(T->data);
        PreOrder(T->lchild);
        PreOrder(T->rchild);
    }
}
```

#### （2）中序遍历

```c
void InOrder(BiTree T) {
    if (T) {
        InOrder(T->lchild);
        visit(T->data);
        InOrder(T->rchild);
    }
}
```

#### （3）后序遍历

```c
void PostOrder(BiTree T) {
    if (T) {
        PostOrder(T->lchild);
        PostOrder(T->rchild);
        visit(T->data);
    }
}
```

#### （4）层次遍历

借助队列实现。

```c
void LevelOrder(BiTree T) {
    if (T == NULL) {
        return;
    }

    InitQueue(Q);
    EnQueue(Q, T);

    while (!IsEmpty(Q)) {
        DeQueue(Q, p);
        visit(p->data);

        if (p->lchild) {
            EnQueue(Q, p->lchild);
        }

        if (p->rchild) {
            EnQueue(Q, p->rchild);
        }
    }
}
```

#### （5）由遍历序列构造二叉树

- 仅凭先序、后序或中序中的任意一种序列，一般不能唯一确定二叉树。
- 先序序列 + 中序序列：可以唯一确定二叉树。
- 后序序列 + 中序序列：可以唯一确定二叉树。
- 层序序列 + 中序序列：可以唯一确定二叉树。

> 前提：遍历序列对应同一棵二叉树，且结点值能够唯一标识结点。

## 三、线索二叉树

### 1. 基本概念

普通二叉链表中存在大量空的左、右孩子指针。线索二叉树利用这些空指针存储结点在某种遍历次序下的前驱或后继。

- `LTag = 0`：`lchild` 指向左孩子。
- `LTag = 1`：`lchild` 指向前驱。
- `RTag = 0`：`rchild` 指向右孩子。
- `RTag = 1`：`rchild` 指向后继。

> 前驱和后继取决于采用的遍历方式。例如，中序线索二叉树中的前驱和后继是中序遍历序列中的前一个、后一个结点。

### 2. 中序线索化

设置指针 `pre`，保存当前结点在中序遍历中的前一个结点。

```c
void InThreading(BiThrTree p) {
    if (p) {
        InThreading(p->lchild);

        if (!p->lchild) {
            p->LTag = 1;
            p->lchild = pre;
        } else {
            p->LTag = 0;
        }

        if (!pre->rchild) {
            pre->RTag = 1;
            pre->rchild = p;
        } else {
            pre->RTag = 0;
        }

        pre = p;

        InThreading(p->rchild);
    }
}
```

> 注意：这是常见的线索化核心逻辑。实际实现时，需要正确初始化 `pre`，并处理头结点、空树和遍历结束时的后继线索。

## 四、树与森林

### 1. 树的存储结构

#### （1）双亲表示法

使用数组存储结点，同时记录每个结点的双亲结点位置。

- 优点：查找双亲方便。
- 缺点：查找孩子通常需要遍历数组。

#### （2）孩子表示法

使用顺序表存储结点，每个结点附带一个链表，用于存放其所有孩子结点的位置。

- 优点：查找孩子方便。
- 缺点：查找双亲不方便。

#### （3）孩子兄弟表示法

又称左孩子右兄弟表示法。

- `lchild`：指向该结点的第一个孩子。
- `rchild`：指向该结点的下一个兄弟。

特点：可以用二叉链表形式存储普通树，并实现树与二叉树之间的转换。

### 2. 森林与二叉树的转换

#### （1）森林转换为二叉树

1. 将森林中的每棵树转换为孩子兄弟表示的二叉树。
2. 将各棵树的根结点视为兄弟结点。
3. 将后一棵树的根连接为前一棵树根的右兄弟。
4. 最终得到一棵二叉树。

#### （2）二叉树转换为森林

1. 将根结点与其右孩子之间的连接断开。
2. 按右兄弟关系拆分为若干棵二叉树。
3. 将每棵二叉树还原为普通树。

### 3. 树、森林与二叉树的遍历对应关系

| 原结构 | 遍历方式 | 对应二叉树遍历 |
|---|---|---|
| 树 | 先根遍历 | 先序遍历 |
| 树 | 后根遍历 | 中序遍历 |
| 森林 | 先序遍历 | 先序遍历 |
| 森林 | 中序遍历 | 中序遍历 |

> 记忆：树的先根遍历对应二叉树先序遍历；树的后根遍历对应二叉树中序遍历。

## 五、哈夫曼树（最优二叉树）

### 1. 基础概念

- 结点权值：赋予结点的数值。
- 结点的带权路径长度：从根结点到该结点的路径长度乘以该结点的权值。
- 树的带权路径长度（WPL）：树中所有叶子结点的带权路径长度之和。

\[
WPL=\sum_{k=1}^{n}w_k l_k
\]

其中：

- \(w_k\)：第 \(k\) 个叶子结点的权值。
- \(l_k\)：根结点到第 \(k\) 个叶子结点的路径长度。

哈夫曼树的特点：WPL 最小。

计算哈夫曼树的 WPL 时，可以将所有非叶子结点的权值相加。

### 2. 哈夫曼树的构造步骤

给定 \(n\) 个叶子结点的权值：

1. 建立森林 \(F\)，其中每棵树只有一个结点，其权值为给定权值。
2. 在森林中选出根结点权值最小的两棵树，作为一棵新二叉树的左右子树。
3. 新树根结点的权值等于两棵子树根结点权值之和。
4. 从森林中删除原来的两棵树，并将新树加入森林。
5. 重复上述过程，直到森林中只剩下一棵树。

最后得到的树就是哈夫曼树。

### 3. 哈夫曼树的核心性质

1. 不存在度为 1 的结点，即：

   \[
   n_1=0
   \]

2. 若有 \(n\) 个叶子结点，则总结点数为：

   \[
   \boxed{N=2n-1}
   \]

3. 非叶子结点数为：

   \[
   n-1
   \]

4. 哈夫曼树的 WPL 最小。
5. 权值较大的叶子通常离根较近，权值较小的叶子通常离根较远。

### 4. 哈夫曼编码

#### （1）前缀编码

任意一个字符的编码都不能是另一个字符编码的前缀。

例如，编码集合 `0`、`10`、`11` 满足前缀编码的要求；编码集合 `0`、`01` 则不满足，因为 `0` 是 `01` 的前缀。

#### （2）哈夫曼编码的构造

1. 根据字符出现频率构造哈夫曼树。
2. 左分支标记为 `0`，右分支标记为 `1`。
3. 从根结点到某个字符叶子结点的路径所对应的 01 序列，就是该字符的哈夫曼编码。

#### （3）哈夫曼编码的特点

- 哈夫曼编码属于前缀编码。
- 哈夫曼编码是最优前缀编码。
- 在给定字符权值的情况下，其带权平均编码长度最小。
- 权值越大的字符通常获得越短的编码。

题目：一棵哈夫曼树有 115 个总结点，求叶子结点数 \(n\)。

哈夫曼树满足：

\[
N=2n-1
\]

代入：

\[
2n-1=115
\]

\[
2n=116
\]

\[
\boxed{n=58}
\]

答案：C。

### 6. 真题 2020.42（前缀编码简答）

#### （1）如何存储前缀编码？

使用二叉树表示前缀编码树，字符存储在叶子结点中，分支对应编码位。

#### （2）如何译码？

1. 从根结点开始。
2. 读到 `0`，沿左分支前进。
3. 读到 `1`，沿右分支前进。
4. 到达叶子结点时，输出对应字符。
5. 输出后回到根结点，继续读取后续编码。
6. 若沿编码位走到空结点，则说明该编码路径无效。

#### （3）如何判断是否存在前缀冲突？

逐个插入编码：

- 如果某个编码尚未结束，就已经经过一个代表完整编码的叶子结点，则存在前缀冲突。
- 如果某个编码结束时，对应结点已经存在后续编码分支，则存在前缀冲突。

### 7. 易错点汇总

1. 公式 \(2n-1\) 适用于哈夫曼树，因为每个非叶子结点都有两个孩子；不能直接套用于任意二叉树。
2. 前缀编码不等于哈夫曼编码，哈夫曼编码属于前缀编码。
3. 前缀编码树中，完整字符编码应对应叶子结点，内部结点不能同时代表一个完整字符编码。
4. 哈夫曼树的构造过程中，每次选择的是当前森林中权值最小的两棵树。
5. 哈夫曼树不一定唯一，但最小 WPL 相同。
