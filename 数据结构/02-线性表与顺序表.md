# 线性表与顺序表

## 一、线性表的定义

线性表是一种逻辑结构，具有以下特点：

1. 数据元素的个数有限。
2. 数据元素类型相同。
3. 除第一个元素外，每个元素均只有一个直接前驱。
4. 除最后一个元素外，每个元素均只有一个直接后继。

注意：线性表描述的是元素之间的逻辑关系，不规定具体的存储方式。

## 二、顺序表的定义

顺序表是线性表的顺序存储实现。

它将线性表中的元素依次存放在一片连续的存储空间中。

### 1. 地址计算

设：
- b：第一个元素的存储地址
- s：每个元素占用的存储空间大小
- i：元素的位序，从 1 开始

则第 i 个元素的地址为：

LOC(A_i) = b + (i-1)s

原因：第一个元素距离起始地址为 0，第二个元素偏移 s，第三个元素偏移 2s。

### 2. 位序与数组下标

课件中的位序从 1 开始，而 C 语言数组下标通常从 0 开始。

| 元素 | 位序 | 数组下标 |
|---|---:|---:|
| 第一个元素 | 1 | 0 |
| 第二个元素 | 2 | 1 |
| 第 i 个元素 | i | i-1 |

这是顺序表操作中非常容易出错的地方。

## 三、顺序表的基本概念

顺序表通常需要记录：

- 存储空间的起始位置。
- 当前元素个数，即表长。
- 当前分配的存储容量。

表长与容量不是一回事：
- 表长：当前实际存放的元素数量。
- 容量：最多能够存放的元素数量。

例如，容量为 10、表长为 6，说明当前存有 6 个元素，还有 4 个空闲位置。

## 四、顺序表的基本操作

### 1. 初始化

初始化的核心任务：
1. 为元素分配存储空间。
2. 检查空间分配是否成功。
3. 将表长设为 0。

课件使用 malloc 分配数组空间，并通过检查返回值判断分配是否成功。

### 2. 按位取值

根据给定的位序，直接访问对应位置的元素。

由于顺序表支持随机访问，按位取值的时间复杂度为 O(1)。

注意检查位序是否合法，不能访问表长之外的位置。

### 3. 按值查找

从表中逐个检查元素，直到找到目标值或遍历结束。

最坏情况下需要检查全部 n 个元素，时间复杂度为 O(n)。

### 4. 插入操作

在第 i 个位置插入新元素时：

1. 检查插入位置是否合法。
2. 检查顺序表是否还有可用空间。
3. 将第 i 个及其后面的元素依次后移。
4. 将新元素放入空出的位置。
5. 更新表长。

为什么需要后移？

因为顺序表的存储空间连续，插入一个元素后，原来位于插入位置及其后面的元素都需要向后移动，才能维持逻辑顺序。

最坏情况下需要移动大量元素，时间复杂度为 O(n)。

### 5. 删除操作

删除第 i 个元素时：

1. 检查删除位置是否合法。
2. 保存被删除元素（如果操作需要返回该元素）。
3. 将后续元素依次前移，填补空位。
4. 更新表长。

删除后，为保持元素连续，后面的元素需要前移。

最坏情况下时间复杂度为 O(n)。

## 五、顺序表的优缺点

### 优点
- 存储连续。
- 支持随机访问。
- 按位取值效率高。
- 存储结构直观。

### 缺点
- 插入和删除可能需要移动大量元素。
- 需要预先分配存储空间；若容量不足，可能需要扩容。

## 六、复杂度总结

| 操作 | 时间复杂度 |
|---|---|
| 按位取值 | O(1) |
| 按值查找 | O(n) |
| 插入 | O(n) |
| 删除 | O(n) |

说明：查找、插入、删除的实际耗时与目标位置和具体实现有关；表中按一般最坏情况总结。

## 七、本章易错点

1. 线性表是逻辑结构，顺序表是其顺序存储实现。
2. 位序从 1 开始，数组下标通常从 0 开始。
3. 表长不等于容量。
4. 顺序表按位访问快，但插入、删除可能需要移动元素。
5. 插入时从后向前移动元素，避免覆盖尚未移动的数据；删除时将后续元素向前移动。
